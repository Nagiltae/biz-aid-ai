주의: cases-v2 맞춤 추천 3문항(V2-16~18)의 기대 공고가 Top3에 계속 남는지 반드시 확인해야 한다.

### (3) 근거 순위(IMP-004)

| 후보 | 내용 | 기대 효과 | 응답 시간 | 메모리 | Bedrock 비용 | 바뀔 파일 |

| **B안(추천)** | 모델 추가 없이, 답변 생성에 넘기는 상위 조각의 바로 앞뒤 조각(같은 문서 이웃)을 함께 넘긴다 | 정답 조각이 2~3위여도 문맥이 이어져 답변 근거가 더 완전해짐(Hit 수치 자체는 그대로) | +0~0.05초(Qdrant 조회) | 0 | 질문당 입력 token +30~60% → 문서 질문 1회 ≈ +$0.001~0.002 | `rag/service.py`(context 구성), `contracts/schemas/rag*.json`, 테스트 |

추천 이유: 서비스 방식에서 Hit@3이 이미 12/12이고 답변 생성은 상위 5개를 받는다. 그래서 순위 자체를 고쳐도 체감 효과가 작고, 재정렬 모델은 8GB 서버에 부담이 크다. 재정렬 모델 도입은 AGENTS 규칙상 별도 승인 대상이기도 하다. 셋 중 우선순위는 가장 낮다.
