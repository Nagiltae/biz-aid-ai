# feature-development

현재 Phase에서는 추가 workflow/reference가 필요하지 않음. 아래 본문과 연결된 Context / Rule로 작업 범위를 확인한다.

현재 Task의 허용 범위와 Acceptance Criteria를 확인하고 현재 production code와 Contract 경계를 보존한다.
영향받는 계약과 검증을 먼저 확인하고 관련 Unit / Integration을 작성한다.
check-all과 작업 Report를 갱신한다. 전체 DoD·Git 절차는 [workflow](../../docs/workflow.md)를 따른다.
